# scGPT Whole-human redistribution record

Verification date: 2026-07-02

## Decision

The pinned scGPT source and Whole-human checkpoint are eligible for the
current Runtime Box. The official project is MIT-licensed and distributes the
checkpoint from its own model zoo without separate checkpoint terms. The box
must preserve the upstream license, copyright notice, checkpoint attribution,
and notices from every packaged Python distribution. If the publisher adds
separate model terms, publication must stop until they are reviewed.

The reviewed source revision is
`cebd6fae655b9c585a4807daa3ac31bb764f06b4`, and every source and model asset
in the recipe is content-addressed. Any source revision, asset, Python
runtime, or dependency-lock change requires a new audit.

This is an engineering compliance record, not legal advice.
