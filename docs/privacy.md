When you visit the Website, Cloudflare and related infrastructure may process technical data necessary to serve the Website, maintain security, prevent abuse, and ensure network performance. This may include:

- browser type and version;
- device type;
- operating system;
- referring URL;
- requested pages or resources;
- timestamps;
- approximate location derived from network information;
- diagnostic and security logs.

This processing is necessary to make the Website available, secure, and reliable.

### 3.2 Cloudflare Web Analytics

We use **Cloudflare Web Analytics** to understand how the Website is used and how it performs.

Cloudflare Web Analytics may collect privacy-focused analytics information such as:

- page views;
- referrers;
- browser type;
- device type;
- country or approximate region;

- aggregated traffic statistics.

Cloudflare Web Analytics is intended to provide website analytics without relying on traditional cross-site tracking cookies. However, technical information may still be processed by Cloudflare as part of providing analytics and network services.

### 3.3 Google Analytics

We may use **Google Analytics** to measure Website traffic and understand how visitors interact with the Website.

You can learn more about how Google processes data by visiting Google’s privacy documentation and Google Analytics documentation.
