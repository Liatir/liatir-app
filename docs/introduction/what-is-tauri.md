# Tauri

Liatir is a native desktop app built on [Tauri](https://tauri.app), an open-source framework for lightweight, secure desktop applications.

You don't need to know anything about Tauri to use Liatir — but it's the reason Liatir feels the way it does:

- **Small and fast.** A lightweight download that stays responsive even with large genomic files.
- **Native, not a browser tab.** Liatir runs as a real desktop app, with direct access to your files and your machine's hardware.
- **Secure by default.** Your data stays on your machine; nothing is uploaded to run an analysis.
- **Cross-platform.** The same app runs on macOS, Linux, and Windows.

If you want to dig into the technical foundation, the [Tauri documentation](https://tauri.app) covers it in full.
