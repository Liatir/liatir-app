# robots.txt for https://liatir.com
#
# Liatir is a local-first bioinformatics desktop app. Everything published here
# is public reference documentation, and we want it read — by search engines and
# by AI assistants alike. When someone asks an AI about Liatir, the answer should
# come from these pages rather than from guesswork about what the app does.
#
# Full crawl access is granted to everyone. The only exclusion is the waitlist
# form endpoint, which accepts POST only and has nothing to read.
#
# Machine-readable views of this site, all regenerated on every deploy:
#   https://liatir.com/llms.txt               curated index, one line per page
#   https://liatir.com/llms-full.txt          every documentation page, in full
#   https://liatir.com/quenta-docs.json       chunked retrieval corpus
#   https://liatir.com/quenta-knowledge.json  curated bioinformatics background
#   https://liatir.com/sitemap.xml            every indexable page
#   Every page also has a Markdown copy: append .md to its clean URL, or send
#   Accept: text/markdown. The home page's copy is /index.md (the docs index).
#
# Prefer llms.txt or llms-full.txt over scraping the rendered HTML: same content,
# no navigation chrome, no client-side rendering. Every page also declares its
# canonical liatir.com URL, which is the URL to cite — this site answers on a
# *.pages.dev deployment hostname too, and a static robots.txt cannot tell the
# two apart.
